## ⚡ Asosiy Imkoniyatlar (Key Features)

- **🌐 3D Interactive Cyber Core:** Three.js orqali yaratilgan golografik aylanuvchi Icosahedron, yadro, orbital halqalar, fazoviy cyber grid va sichqoncha parallaksi.
- **📟 Interaktiv Hacker Terminali (CLI):** Haqiqiy buyruqlar interpretatori (`help`, `whoami`, `skills`, `projects`, `achievements`, `exploit`, `matrix`, `theme`, `admin`, `cat resume`, `cat flag.txt`).
- **🌍 3 Tilli Tarjima Tizimi (UZ / RU / EN):** O'zbekcha, Ruscha va Inglizcha to'liq lokalizatsiya.
- **📑 Alohida Sahifalar (Dedicated Page Routing):** Asosiy, Mahoratlar, Loyihalar, Yutuqlar, Terminal va Bog'lanish sahifalari o'z marshrutiga ega.
- **🖼️ Yutuqlar va Natijalar (Achievements Archive):** Rasm yuklash, Lightbox modal, toifalar va isbot havolalari.
- **🔒 Yashirin Admin Panel (CRUD):** 
  - Yangi yutuq qo'shish (Create)
  - Ko'rish (Read)
  - Tahrirlash (Update)
  - O'chirish (Delete)
  - Oddiy tashrif buyuruvchilardan 100% yashirilgan!
- **🛡️ Kiber-Xavfsizlik Himoyasi:** `Ctrl + U` (View Source), `F12`, DevTools qisqartmalari va kontekst menyu bloklangan.
- **🎵 Web Audio Tovush Dizayni:** Sintez qilingan futuristic audio effektlar.
- **🔄 24/7 Doimiy Fondagi Xizmat (PM2 & Windows Autostart):** Kompyuter o'chib-yonsa ham fonda avtomatik ishlab turadi.

## 🚀 Ishga Tushirish (Quick Start)

### 1. Bog'liqliklarni o'rnatish
```bash
npm install
```

### 2. Dasturiy ishga tushirish (Dev Server)
```bash
npm run dev
```
Brauzerda ochish: `http://localhost:5173/`

### 3. Doimiy 24/7 fonda ishga tushirish (Permanent PM2)
Loyihada tayyorlangan bir bosishlik skriptlar:
- **`start_permanent.bat`** — PM2 orqali 24/7 fonda ishga tushirish (`http://localhost:5000`).
- **`stop_permanent.bat`** — Fondagi xizmatni to'xtatish.
- **`install_autostart.bat`** — Windows yoqilganda avtomatik fonda ishga tushishini sozlash.
